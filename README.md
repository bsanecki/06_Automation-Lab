# Automation Portfolio

A visual portfolio of four workflow automation projects focused on email handling, social media publishing, and website monitoring. The descriptions and screenshots explain what each workflow is designed to do and how it can help reduce repetitive manual tasks.

**This repository presents the workflows for portfolio purposes. It contains descriptions and screenshots, not the complete automation exports, connected accounts, or access to the live services.**

## Projects

### 1. Email Support Automation

**Purpose:** Reduce manual work when handling incoming support emails.

The workflow is designed to check incoming Microsoft Outlook messages, filter selected automated or system emails, and send an acknowledgement when appropriate. It also sends a Discord notification with the sender's details and the email subject.

**Services:** Microsoft Outlook, Discord, Activepieces.

[Read the project description](01_email_support_automation/README.md) · [View project files and screenshots](01_email_support_automation/)

---

### 2. Facebook Publishing Automation

**Purpose:** Make scheduled Facebook Page publishing easier to manage.

The workflow is designed to publish prepared Facebook Page posts using images and captions stored in Google Drive. It helps avoid reposting content that has already been published and sends a Discord notification when the queue of unpublished posts becomes low.

**Services:** Make.com, Google Drive, Facebook Pages, Discord.

[Read the project description](02_make_facebook_automation/README.md) · [View project files and screenshots](02_make_facebook_automation/)

---

### 3. TikTok Content Publishing Automation

**Purpose:** Organize and prepare TikTok posts for scheduled publishing.

The workflow is designed to prepare TikTok content using post folders, images, and related information stored in Google Drive. It passes the prepared content to the LetMePost publishing integration, supports posts with multiple images, and sends Discord notifications.

**Services:** Activepieces, Google Drive, LetMePost, Discord.

[Read the project description](03_tiktok_content_automation/README.md) · [View project files and screenshots](03_tiktok_content_automation/)

---

### 4. Website Monitoring & Alerts

**Purpose:** Help notice website availability problems without having to check each website manually.

The workflow is designed to check website availability on a schedule. It records the monitoring history in Google Sheets and sends a Discord alert when a check indicates a potential availability problem.

**Services:** Activepieces, HTTP monitoring, Google Sheets, Discord.

[Read the project description](04_website_monitoring_alerts/README.md) · [View project files and screenshots](04_website_monitoring_alerts/)

---

## Tools used

- **Activepieces** - email support, TikTok content workflow, and website monitoring.
- **Make.com** - Facebook publishing workflow.
- **Connected services** - Microsoft Outlook, Google Drive, Facebook Pages, LetMePost, Discord, and Google Sheets.
